# 🧠 MindDump

**MindDump** is a sleek, localStorage-based note-taking app built with React. Designed to showcase strong frontend skills, it supports essential features like dark mode, search, pinning, undo delete, and more — without relying on any backend or external databases.

## ✨ Features

- 📝 Add, edit, delete notes
- 📌 Pin and unpin notes
- 🔍 Real-time search/filter
- 🧭 Undo delete functionality
- 🌙 Dark mode toggle
- 💾 Persistent data with `localStorage`
- 🔄 Autosave & instant updates
- ⚡ Fast and lightweight (no backend)


## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v14+)
- npm or yarn

### Installation

git clone https://github.com/4512yasir/minddump.git
cd minddump
npm install
npm run dev
